# credit_portfolio_loss_distribution

How to use this repository:

- Read and implement the instructions laid out in `task.pdf`.
- Data can be found in the data folder, with the files to be used being `loan_book.csv`, `systematic_shocks.csv` and `pd_mapping.csv`.
- The `src` folder contains the code used to generate the synthetic data (this is not relevant for the task), and an example solution to the task problem. This code is not the easiest to follow as it is designed to be used with massive datasets, however, it may provide some inspiration if you get stuck.

Beyond that, enjoy learning about credit risk modelling!
